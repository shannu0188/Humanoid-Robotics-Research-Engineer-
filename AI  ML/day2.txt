# DAY 2 — POINT 4: ARTIFICIAL INTELLIGENCE (AI)

## 1. What is Artificial Intelligence (AI)?

Artificial Intelligence (AI) is a field of computer science that focuses on building systems that can perform tasks associated with human intelligence.

AI can help systems perform tasks such as:

* Perception
* Learning
* Reasoning
* Planning
* Decision-making
* Understanding language

### Simple Definition:

AI = Making machines capable of performing intelligent tasks.

### Example in Humanoid Robotics:

Camera/Sensors
↓
AI understands the environment
↓
Recognizes objects
↓
Makes a decision
↓
Robot performs an action

## 2. What is Machine Learning (ML)?

Machine Learning (ML) is a part of AI where computers learn patterns from data and use those patterns to make predictions or decisions.

Instead of programming every rule manually, we provide data and allow the ML model to learn patterns.

### Basic Process:

Training Data
↓
ML Algorithm / Model
↓
Learns Patterns
↓
New Data
↓
Prediction / Decision

### Example:

Give the model many images of cups and non-cups.

The model learns patterns from those examples.

Later, when it receives a new image, it can predict whether the object is a cup.

### AI vs ML:

AI = Broad field of intelligent systems.

ML = An approach within AI where systems learn patterns from data.

Deep Learning = A type of ML based mainly on neural networks.

## 3. Types of Machine Learning

There are three major types:

### 1. Supervised Learning

The model learns from labeled data.

Example:

Image → Label
Dog → Dog
Cat → Cat

The model learns from these examples and predicts labels for new data.

Robotics applications:

* Object recognition
* Person detection
* Sensor-value prediction

### 2. Unsupervised Learning

The model learns from data without predefined labels and tries to discover patterns or groups.

Basic process:

Data
↓
ML Model
↓
Finds Patterns / Groups

Robotics applications:

* Finding patterns in sensor data
* Grouping similar objects or movements

### 3. Reinforcement Learning (RL)

The system learns by interacting with an environment.

It receives rewards for desired actions and penalties for undesirable actions.

Robot
↓
Takes Action
↓
Environment
↓
Reward / Penalty
↓
Learns
↓
Tries Again

Robotics applications:

* Walking
* Balance
* Movement control
* Manipulation

## 4. How AI is Used in Humanoid Robotics

### 1. Vision & Perception

AI helps robots understand information from cameras and sensors.

Camera/Sensors
↓
AI
↓
Objects / People / Environment

Example:
A humanoid robot identifies a person, table, chair, or cup.

### 2. Decision Making

AI can help the robot decide what action to take based on its environment.

Example:

Robot sees a cup
↓
AI understands the situation
↓
Plans to pick up the cup
↓
Robot performs the action

### 3. Manipulation

AI can help robots interact with objects.

Examples:

* Pick up an object
* Move an object
* Place an object
* Use tools

### 4. Locomotion & Balance

AI, especially Reinforcement Learning, can be used for movement-related tasks.

Examples:

* Walking
* Maintaining balance
* Recovering from disturbances
* Learning movement strategies

### 5. Human–Robot Interaction

AI can help humanoid robots understand human communication.

Human Speech
↓
AI
↓
Understanding
↓
Robot Response / Action

### 6. Multimodal AI

Advanced humanoid robots can combine different types of information.

Vision + Speech + Touch + Sensors
↓
AI
↓
Understanding
↓
Action

## KEY POINT

AI helps humanoid robots perceive their environment, learn, reason, plan, and make decisions that support physical actions.
