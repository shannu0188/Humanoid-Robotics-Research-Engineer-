📐 Topic 2: Matrices

A matrix is a rectangular arrangement of numbers organized into rows and columns.

Example:

$$ A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix} $$

Here:

2 rows → 1 2 and 3 4
2 columns → 1 3 and 2 4
So this is a 2 × 2 matrix
🤖 Why do robots use matrices?

Matrices are extremely important in robotics because they help represent things like:

Robot position
Robot orientation
Rotation of joints
Coordinate transformations
Movement of robot arms and body parts

For example, later when we study robot arm kinematics, matrices will help us calculate where the robot's hand is located.

Simple way to remember

Vector → represents a quantity/direction

Matrix → organizes numbers and can transform mathematical data

📐 Vector Operations

Vector ಮೇಲೆ basic ಆಗಿ 3 operations important:

1️⃣ Vector Addition

Two vectors add ಮಾಡುವುದು.

$$ A = \begin{bmatrix} 2\\ 3 \end{bmatrix} ,\quad B = \begin{bmatrix} 4\\ 1 \end{bmatrix} $$

Add:

$$ A+B = \begin{bmatrix} 2+4\\ 3+1 \end{bmatrix} = \begin{bmatrix} 6\\ 4 \end{bmatrix} $$

🤖 Robotics example: Robot ಒಂದು directionನಲ್ಲಿ 2 m move ಆಗಿ, ನಂತರ ಇನ್ನೊಂದು movement 4 m ಆಗಿದ್ದರೆ, movements ಅನ್ನು combine ಮಾಡಲು vector addition ಬಳಸಬಹುದು.

2️⃣ Vector Subtraction
$$ A-B = \begin{bmatrix} 2-4\\ 3-1 \end{bmatrix} = \begin{bmatrix} -2\\ 2 \end{bmatrix} $$

ಇದು ಎರಡು vectors ನಡುವಿನ difference ಕಂಡುಹಿಡಿಯಲು useful.

3️⃣ Scalar Multiplication

ಒಂದು vector ಅನ್ನು ಒಂದು number‌ನಿಂದ multiply ಮಾಡುವುದು.

$$ A = \begin{bmatrix} 2\\ 3 \end{bmatrix} $$

Multiply by 2:

$$ 2A = \begin{bmatrix} 2\times2\\ 2\times3 \end{bmatrix} = \begin{bmatrix} 4\\ 6 \end{bmatrix} $$

🤖 ಇದು movement ಅನ್ನು scale ಮಾಡಲು useful.

🧠 Remember

Addition → combine

Subtraction → difference

Scalar multiplication → scale

📐 Topic 4 — Basic Matrix Operations

For today, we need to understand 2 basic operations:

Matrix Addition
Matrix Multiplication
1️⃣ Matrix Addition

Two matrices can be added when they have the same dimensions.

Example:

$$ A= \begin{bmatrix} 1 & 2\\ 3 & 4 \end{bmatrix} $$ $$ B= \begin{bmatrix} 5 & 6\\ 7 & 8 \end{bmatrix} $$

Add corresponding elements:

$$ A+B= \begin{bmatrix} 1+5 & 2+6\\ 3+7 & 4+8 \end{bmatrix} $$

So:

$$ A+B= \begin{bmatrix} 6 & 8\\ 10 & 12 \end{bmatrix} $$

Remember: Matrix addition = add corresponding positions.

2️⃣ Matrix Multiplication

This is more important for robotics.

Take:

$$ A= \begin{bmatrix} 1 & 2\\ 3 & 4 \end{bmatrix} $$

and

$$ B= \begin{bmatrix} 5 & 6\\ 7 & 8 \end{bmatrix} $$

For the first element:

$$ (1\times5)+(2\times7)=19 $$

For the second:

$$ (1\times6)+(2\times8)=22 $$

For the third:

$$ (3\times5)+(4\times7)=43 $$

For the fourth:

$$ (3\times6)+(4\times8)=50 $$

Therefore:

$$ AB= \begin{bmatrix} 19 & 22\\ 43 & 50 \end{bmatrix} $$
🤖 Why is this important for humanoid robotics?

Later, matrices are used for coordinate transformations and rotations.

For example:

Robot arm
   ↓
Joint 1
   ↓
Joint 2
   ↓
Joint 3
   ↓
Hand

We can use matrices to mathematically calculate how the position of one part changes when the joints move.

# DAY 2 — MATHEMATICS

1. VECTORS

---

Definition:
A vector is a quantity that has both magnitude and direction.

Magnitude = How much?
Direction = Which direction?

Example:
A robot moves 5 meters forward.

Magnitude = 5 m
Direction = Forward

Vector representation:

v = [ 3 ]
[ 4 ]

Robotics Applications:

* Position
* Displacement
* Velocity
* Acceleration
* Force
* Robot movement

Key Point:
Vector = Magnitude + Direction

2. MATRICES

---

Definition:
A matrix is a rectangular arrangement of numbers in rows and columns.

Example:

A = [ 1  2 ]
[ 3  4 ]

Rows = 2
Columns = 2

Therefore, A is a 2 × 2 matrix.

Matrix dimensions:
Rows × Columns

Robotics Applications:

* Coordinate transformations
* Rotation
* Position representation
* Orientation
* Robot kinematics
* Robot movement calculations

Key Point:
Matrix = Numbers arranged in rows and columns.

3. VECTOR OPERATIONS

---

A. Vector Addition

A = [ 2 ]       B = [ 4 ]
[ 3 ]           [ 1 ]

A + B = [ 2 + 4 ]
[ 3 + 1 ]

```
  = [ 6 ]
    [ 4 ]
```

Rule:
Add corresponding components.

Key Point:
Vector Addition = Combine vectors.

B. Vector Subtraction

A = [ 2 ]       B = [ 4 ]
[ 3 ]           [ 1 ]

A - B = [ 2 - 4 ]
[ 3 - 1 ]

```
  = [ -2 ]
    [ 2 ]
```

Rule:
Subtract corresponding components.

Key Point:
Vector Subtraction = Find the difference.

C. Scalar Multiplication

A = [ 2 ]
[ 3 ]

2A = [ 2 × 2 ]
[ 2 × 3 ]

= [ 4 ]
[ 6 ]

Rule:
Multiply every component by the scalar.

Key Point:
Scalar Multiplication = Scale the vector.

4. BASIC MATRIX OPERATIONS

---

A. Matrix Addition

A = [ 1  2 ]
[ 3  4 ]

B = [ 5  6 ]
[ 7  8 ]

A + B = [ 1+5  2+6 ]
[ 3+7  4+8 ]

```
  = [ 6   8  ]
    [ 10  12 ]
```

Rule:
Add corresponding elements.

Condition:
Both matrices must have the same dimensions.

Key Point:
Matrix Addition = Add corresponding elements.

B. Matrix Multiplication

A = [ 1  2 ]
[ 3  4 ]

B = [ 5  6 ]
[ 7  8 ]

First element:
(1 × 5) + (2 × 7) = 19

Second element:
(1 × 6) + (2 × 8) = 22

Third element:
(3 × 5) + (4 × 7) = 43

Fourth element:
(3 × 6) + (4 × 8) = 50

Therefore:

AB = [ 19  22 ]
[ 43  50 ]

Important Rule:
The number of columns in the first matrix
must equal the number of rows in the second matrix.

Example:

2 × 3  ×  3 × 2  =  2 × 2
